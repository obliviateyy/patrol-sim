# 运行与结业提交

按本文件从干净的仓库副本运行一次，并确认验收人员能访问仓库和成果材料。

## 本地运行

- 使用的操作系统和环境版本：Windows 10/11 或 Linux；Python 3.11（3.10 及以上可用）；Docker 24 及以上（仅部署时需要）。
- 依赖安装（在项目根目录执行）：

  ```bash
  python -m pip install -r backend/requirements.txt
  ```

- 启动顺序：本项目由 Flask 同时提供页面和 API，只有一个进程，不需要分别启动前后端。

  ```bash
  cd backend
  # Windows CMD
  set SERVE_FRONTEND=1 && python app.py
  # Windows PowerShell
  $env:SERVE_FRONTEND=1; python app.py
  # Linux / Git Bash
  SERVE_FRONTEND=1 python app.py
  ```

- 页面入口为 `http://localhost:5000`，后端 API 地址为 `http://localhost:5000/api`。
- 启动后执行：打开页面，点击「前进」，看到机器人向右移动一格且状态显示「移动中」；再持续点击前进直到地图右边界，机器人停在边界内且状态显示「受阻」，此时 `curl http://localhost:5000/api/robot` 的返回值与页面一致。
- 单元测试（在 `backend` 目录执行）：

  ```bash
  python -m pytest tests -q
  ```

  预期看到 `10 passed`。

如果希望前端单独起在另一个端口，把 `frontend/app.js` 顶部的 `API_BASE` 改为 `"http://localhost:5000"`，再任选静态服务器托管 `frontend/`；后端需在 `app.py` 所在目录保持默认启动（不设置 `SERVE_FRONTEND`）。

依赖说明、接口示例见[后端 README](../backend/README.md)，页面说明见[前端 README](../frontend/README.md)。

## Docker 部署

1. 在项目根目录执行命令，所需 Docker 环境为 Docker Engine 24+ 且已安装 Compose 插件。
2. 无需额外配置文件；服务监听容器内 5000 端口，映射到宿主机 8000 端口。如需改端口，编辑 `docker-compose.yml` 的 `ports`。
3. 构建并启动：

   ```bash
   docker compose up --build
   ```

4. 打开 `http://localhost:8000`，点击「前进」验证页面和 API；预期机器人移动，状态面板同步更新。`curl http://localhost:8000/api/map` 应返回地图尺寸和障碍物数组。
5. 停止服务：

   ```bash
   docker compose down
   ```

## 在线部署（PythonAnywhere）

本项目已部署到 PythonAnywhere 免费账户（无需信用卡）。

1. 注册免费账户后，把 `backend/` 与 `frontend/` 上传到 `/home/<用户名>/patrol-sim/`，保持 `patrol-sim/backend/` 与 `patrol-sim/frontend/` 的结构。
2. 在 Web 页创建 Web App（Manual configuration，Python 3.10+），并把 WSGI 文件 `/var/www/<用户名>_pythonanywhere_com_wsgi.py` 改为：

   ```python
   import os
   import sys

   project_home = '/home/<用户名>/patrol-sim'
   backend_dir = os.path.join(project_home, 'backend')
   if backend_dir not in sys.path:
       sys.path.insert(0, backend_dir)
   os.environ['SERVE_FRONTEND'] = '1'

   from app import app as application
   ```

3. 在 Bash 控制台执行 `pip install --user flask`（需 Flask 2.0+）。
4. 回 Web 页点击 Reload，访问 `https://<用户名>.pythonanywhere.com/`。

部署成功后，把实际地址填入根 README 的「在线演示」和下方「结业材料」表。

> 免费账户每 3 个月需登录 Web 页点「Run until ...」延长网站有效期。
